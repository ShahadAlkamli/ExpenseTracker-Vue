# Expense Tracker – Frontend (Vue.js)

This is the frontend web application for the Expense Tracker project.  
It provides a simple and clean user interface for adding, displaying, and managing expenses.

---

## 🚀 Features
- Modern interface built with **Vue.js**
- Add, view, and delete expenses
- Responsive layout for mobile and desktop
- Can connect to the Django backend API

---

## 🧰 Tech Stack
- **Vue 3**
- **JavaScript**
- **Vite**
- **HTML & CSS**

---

## 📁 Project Structure
```
src/
  components/
  views/
  assets/
  App.vue
  main.js
index.html
vite.config.js
```

---

## ▶️ Run the Project Locally

### 1️⃣ Install dependencies
```bash
npm install
```

### 2️⃣ Start the development server
```bash
npm run dev
```

The app will run at:

```
http://localhost:5173/
```

---

## 🔗 Connecting to the Backend (Optional)

If you are using the Django backend:

1. Start the backend at `http://127.0.0.1:8000/`
2. Update the API URLs inside your Vue components or services
3. Use Fetch or Axios to communicate with the backend API
